DisasterRescueAI

DisasterRescueAI is a coding-only autonomous disaster-response simulation designed to demonstrate how an intelligent rescue robot can navigate hazardous environments, locate survivors, and plan safe routes.

🚨 Overview

DisasterRescueAI simulates a rescue operation in which an autonomous robot must reach a survivor while navigating around obstacles and responding to different disaster scenarios.

The project focuses on the core concepts behind autonomous disaster-response robotics without requiring physical robotic hardware.

🤖 Key Features

Autonomous Rescue Robot
The robot operates within the simulated environment and plans its own movement.

Survivor Detection & Targeting
The system identifies the survivor's location and sets it as the rescue target.

A Pathfinding*
Uses the A* algorithm to calculate an efficient path around obstacles.

Obstacle Avoidance
The robot dynamically navigates through blocked areas instead of moving directly toward the target.

Multiple Disaster Modes
Simulates different disaster environments and conditions.

Command-Center Interface
Provides a centralized interface for observing and controlling the rescue simulation.

Coding-Only Prototype
Designed to explore robotic intelligence and autonomous decision-making without physical hardware.
